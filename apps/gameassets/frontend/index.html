项目参数

透明底：chroma=白底色键（快，轮廓硬）；rembg=AI 抠图（毛发自然，首次用要下 ~176MB 模型）。

画幅不用在这里调：场景按每条场景的「用途」定 （战斗 16:9 1152×640 / 平铺 1:1 1024 / 竖屏 2:3 768×1152 / 横幅 9:4 1152×512 / 等距 896）， 怪物按「等级」定（杂兵 640 / 精英 768 / 首领 896 / 终局 1024）——都在「编辑方案」里逐条改。
